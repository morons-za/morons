# Bug Fix: Filter Dropdowns Not Working

## 🐛 Bug Description

The filter dropdowns (Registration and Owner) on the airspace violations page do not work. When users select an aircraft or company from the dropdowns, the table does not filter - it continues to show all flights.

## 🔍 Root Cause Analysis

**Confidence Rating: 95%**

### The Problem

In `/backend/scripts/app.js.template`, the `setupEventListeners()` function is defined (line 292) but **never called**. This function is responsible for attaching event listeners to the filter dropdowns that trigger the `applyFilters()` function when users make selections.

### Code Flow Analysis

1. **Initialization Flow:**
   - `loadFlightData()` is called on page load
   - This calls `initializeApp()` when data is loaded
   - `initializeApp()` calls:
     - ✅ `initializeMap()`
     - ✅ `populateRegistrationDropdown()`
     - ✅ `populateOwnerDropdown()`
     - ✅ `renderTable()`
     - ❌ **MISSING**: `setupEventListeners()`

2. **What `setupEventListeners()` Does:**
   - Attaches `change` event listeners to:
     - `registrationFilter` dropdown
     - `ownerFilter` dropdown
     - `dateStart` input
     - `dateEnd` input
   - All listeners call `applyFilters()` when triggered

3. **Why It Broke:**
   - The `setupEventListeners()` function exists and is correctly implemented
   - However, it's never invoked during app initialization
   - Without event listeners, dropdown changes don't trigger filtering
   - The `applyFilters()` function exists and works correctly, but it's never called

### When Was This Introduced?

**Likely during static site rebuild or refactoring**

This bug was likely introduced when:
1. The static site build process was modified
2. The initialization flow was refactored
3. Event listener setup was moved to a separate function but the call was forgotten

### Evidence

- `setupEventListeners()` function is properly defined (lines 292-336)
- `applyFilters()` function is properly defined (lines 338-353)
- Filter logic is correct (registration, owner, date matching)
- Dropdowns are populated correctly
- **Missing**: The connection between dropdowns and filter function

## ✅ The Fix

Add `setupEventListeners()` call to `initializeApp()` function:

```javascript
function initializeApp() {
    console.log('🎯 initializeApp() called with', flightData.length, 'flights');
    
    // Initialize global variables
    filteredData = Array.isArray(flightData) ? [...flightData] : [];
    
    // Actually call the initialization functions
    initializeMap();
    populateRegistrationDropdown();
    populateOwnerDropdown();
    setupEventListeners();  // ← ADD THIS LINE
    renderTable();
}
```
