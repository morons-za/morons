🚀 Start Server

To use this interface, start the backend server:

cd backend && ./launch.sh

Or manually:

cd backend && node scripts/index-no-auth.cjs

🔧 Admin FAQ

🚀 START Both Servers

Copy and paste into Terminal:

cd && ./launch.sh

✅ Starts backend (4000) + static site (8080) + opens both in browser

🛑 STOP Both Servers

Copy and paste into Terminal:

lsof -ti:4000 -ti:8080 | xargs kill -9

💥 Kills all servers immediately (port 4000 and 8080)

Note: If you used ./launch.sh, you can also press Ctrl+C in the Terminal window where it's running.

🚁 Start Backend Server Only (Advanced)

Why: The backend server processes KML files, validates helicopter flights, generates PNG maps, and provides the API for this admin interface.

Copy and paste this into Terminal:
cd backend && node scripts/index-no-auth.cjs

Then visit: http://localhost:4000

Features: Upload KML files, validate violations, generate flight maps, optimize files for the static site.

🌐 Start Static Site Server Only (Advanced)

Why: The static site must be served via a local web server to load optimized KML files. This project uses http://localhost:8080.

Copy and paste this into Terminal:
cd backend/scripts && node serve-static-site.cjs

Then visit: http://localhost:8080

Note: The static site must run on port 8080 for local testing.

🛑 STOP SERVERS (Important!)

Choose the method that matches how you started the servers:

✅ If you used the Unified Launcher (./launch.sh):

Simply press Ctrl+C in the Terminal window

This will stop BOTH servers automatically and clean up everything. ✨

🔧 If servers are running in background (or Ctrl+C didn't work):

Stop ALL servers with one command:

lsof -ti:4000 -ti:8080 | xargs kill -9

This kills both backend (4000) and static site (8080) servers.

🎯 Stop Individual Servers (Advanced):

Stop Backend Server (port 4000):

lsof -ti:4000 | xargs kill -9

Stop Static Site Server (port 8080):

lsof -ti:8080 | xargs kill -9
🔍 Check if servers are running:
lsof -i :4000 -i :8080

If nothing appears, no servers are running. If you see output, servers are running.

💡 Quick Troubleshooting
Common Issues:
  • "Address already in use" error: Port 8080 is already taken. Free it with lsof -ti:8080 | xargs kill -9 or restart the static-site server.
  • KML files won't load: Make sure you're accessing via http://localhost:8080 and the static site server is running.
  • Backend API not working: Check that the backend server is running on port 4000 and this page shows "🟢 Server Online".
  • Can't upload files: Make sure the backend server is running and you're not blocked by CORS.
Port Reference:
  • Port 8080: Static site (helicopter flight viewer)
  • Port 4000: Backend API (this admin interface)
